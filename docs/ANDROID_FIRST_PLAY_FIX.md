# Android 1.1.0+2018 首次播放修正

報告顯示 4K/60fps 素材先進編輯，1080p 工作檔在背景花 4.7～7.3 秒製作；另有播放中校正 seek，偏差約 1～1.5 秒。累積紀錄包含不同長度素材，10 秒偏差不能直接歸因到目前這支 6.62 秒影片。

修改：
- Android 使用既有準備進度與逾時略過流程，完成工作檔後才開放初次操作；避免首播原檔並同時轉檔。代價是首次匯入需要等待，並非轉檔本身變快。iOS 預設快速進入不變。
- Android 不再呼叫 iOS 專用合成播放器，診斷明確顯示使用逐片段播放器。
- 工作檔要求關鍵幀間隔 0.10 秒，取代 0.25 秒；60fps 的目標約 6 格。編碼器可能忽略要求，仍以實機產物檢查為準。原始匯出檔的品質設定不變。
- Android 校正前讀取即時位置，避免快取位置延遲誤觸校正。一般正向主影片偏差過大時讓時間軸跟隨播放器；其他軌道仍可對準主時間軸。

驗證：準備策略及匯入回歸 7 項通過；後續匯入、互動、原檔匯出相關 17 項通過。Windows 尚未完成 Android 原生建置與實機驗證。`c2.google.avc.encoder` 的硬體替代方案未強制指定，以免裝置無相容編碼器時無法準備。

實機驗收：同一支 4K/60fps 第一次與第二次播放各一次；確認首播已使用工作檔、播放中校正 seek 不再反覆出現，並檢查新工作檔的實際關鍵幀間距。舊工作檔不會因更新自動變成新間距，需重新匯入測試。
